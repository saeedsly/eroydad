اجرای ساده در XAMPP (PHP 7.4.25)
==================================

نشانی موردنظر:
    https://localhost/erooydad

۱) اگر فایل ZIP جدید را قبلاً استخراج کرده‌ای، Apache را Stop کن و پوشهٔ erooydad را در این مسیر به‌روز کن:
    C:\xampp\htdocs\erooydad
   فایل .env موجودت را نگه دار؛ اسکریپت تنظیم هم آن را بازنویسی نمی‌کند. دیتابیس را دوباره Import نکن.

۲) XAMPP Control Panel را باز کن و MySQL را Start کن. از CMD این دستور را اجرا کن:
    C:\xampp\php\php.exe C:\xampp\htdocs\erooydad\deployment\local-xampp\setup-local-test.php

   این کار اتصال و schema را بررسی می‌کند. اگر .env موجود باشد، کلیدهای برنامه را نگه می‌دارد؛ در صورت خطای اتصال، تلاش می‌کند با root پیش‌فرض محلی XAMPP (بدون رمز) فقط تنظیمات DB را خودکار اصلاح کند. اگر .env نباشد، برای نصب پیش‌فرض XAMPP کلیدهای تصادفی و دسترسی محدود برنامه را محلی می‌سازد. دیتابیس و جدول‌ها پاک یا دوباره ساخته نمی‌شوند. اگر برای root رمز تعیین کرده‌ای، اصلاح خودکار با تنظیم پیش‌فرض ممکن نیست. اگر مدیر اولیه وجود نداشته باشد، نام، شماره و رمز او را در پنجره CMD وارد کن؛ رمز را اینجا یا برای کسی نفرست. در Windows هنگام تایپ ممکن است رمز دیده شود.

۳) Apache را Start کن و باز کن:
    https://localhost/erooydad
   اگر HTTPS فعال نیست:
    http://localhost/erooydad

در نصب پیش‌فرض XAMPP نیازی به ویرایش php.ini، httpd.conf، VirtualHost یا Alias نیست. فایل .htaccess در بسته، مسیر را به برنامه هدایت می‌کند. این روش به خوانده‌شدن .htaccess و فعال‌بودن mod_rewrite وابسته است؛ اگر خطای 403/404/500 دیدی، متن خطا را بفرست و فعلاً تنظیم دیگری را دست‌کاری نکن.

این نسخه برای تست محلی است. PHP 7.4 پایان‌عمر است و نباید روی اینترنت عمومی منتشر شود.
