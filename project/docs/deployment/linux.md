# استقرار روی لینوکس (چارچوب)

> **وضعیت:** این سند چارچوب و الزامات را می‌نویسد؛ برخلاف نصب XAMPP، روی سرور لینوکس واقعی در این محیط آزمایش نشده است (بخش ۸۵/۸۶ نقشه‌راه همین را می‌گوید). پیش از انتشار عملیاتی، همان چک‌لیست [`security/release-checklist.md`](../security/release-checklist.md) الزامی است.

## الزامات

- **PHP ≥ 7.4** با `pdo_mysql`، `mbstring`، `openssl`، `fileinfo` (کد با 7.4 نوشته و تست شده؛ ارتقا به 8.x پیشنهادی است ولی خارج از پوشش آزمون فعلی).
- **MySQL 8 یا MariaDB 11.8+** با `utf8mb4`.
- وب‌سرور: Apache + mod_php یا Nginx + PHP-FPM.
- بدون Composer، بدون Node در سرور (Node فقط برای اجرای آزمون‌ها در محیط توسعه است).

## ساختار و امنیت فایل‌سیستم

- **ریشهٔ وب فقط `frontend/public/` باشد** — `backend/`، `database/`، `.env`، `storage/` و `docs/` نباید از اینترنت قابل خواندن باشند (Nginx: فقط `root` مربوط به public؛ Apache: ریشهٔ VirtualHost را همان public بگذار و `.htaccess` موجود را نگه دار).
- `.env` خارج از ریشهٔ وب یا با مسدودسازی دسترسی؛ مجوز فایل 600.
- رازها: `generate-secrets.php` را **روی خود سرور** بزنید، نه روی دستگاه دیگر؛ سپس در `.env`.
- کاربر وب‌سرور مالک `storage/private/` باشد (پشتیبان‌ها آنجا نوشته می‌شوند).

## نصب

1. کد را با `git` یا استخراج بسته روی سرور ببرید.
2. دیتابیس و کاربر اختصاصی بسازید (دسترسی فقط به همان دیتابیس؛ نه root).
3. `database/schema.sql` را یک‌بار Import کنید.
4. `.env` را با `APP_BASE_URL=https://…` و رازهای تولیدشده بسازید.
5. `php deployment/local-xampp/migrate.php` (اسکریپت فقط CLI است؛ روی سرور هم همین مسیر).
6. مدیر اول: `php deployment/local-xampp/create-admin.php`.
7. TLS: مسیر HTTPS (Let's Encrypt یا معادل) و `APP_BASE_URL=https` — کوکی نشست فقط روی HTTPS `secure` می‌شود.
8. به‌روزرسانی بعدی: **فقط** `migrate.php`؛ هرگز schema را دوباره نریز.

## سلامت و پایش

- پنل مدیر → سلامت سامانه (`/admin/system`): نسخهٔ PHP/افزونه‌ها، اتصال دیتابیس، فضای ذخیره‌سازی (`HealthService`).
- لاگ خطا: `error_log` وب‌سرور؛ هر خطای ناشناس فقط `request_id` و نوع کلاس را ثبت می‌کند (بدون دادهٔ حساس) — شناسه در صفحهٔ ۵۰۰ هم نمایش داده می‌شود.
- پشتیبان: [`backup.md`](backup.md).

## محدودیت‌ها و کارهای باز

- زمان‌بندی cron برای پشتیبان/پاک‌سازی داده به محیط سرور وابسته است؛ رابط دستی آن‌ها از پنل موجود است.
- پیکربندی Nginx نمونه و اسکریپت انتشار باز (release) هنوز نوشته نشده — پیش از بهره‌برداری واقعی تکمیل شود.
