# نصب تمیز روی XAMPP (ویندوز)

راهنمای گام‌به‌گام نصب تازه از بستهٔ `eroydad-xampp-php74-updated.zip`. بخش «راستی‌آزمایی دستی» همان چیزی است که در نقشه‌راه بند ۸۵ («آزمون نصب تمیز روی XAMPP ویندوز») باید روی ویندوز واقعی انجام و ثبت شود؛ بقیهٔ مراحل با `tests/clean-install-test.mjs` به‌صورت خودکار هم شبیه‌سازی می‌شوند.

## پیش‌نیازها

- ویندوز با **XAMPP** شامل **PHP 7.4** و MariaDB/MySQL.
- بدون نیاز به Composer، Node یا اتصال اینترنت (همهٔ دارایی‌ها داخل بسته است).

## روش سریع: نصب‌کنندهٔ وب (پیشنهادی)

بعد از استخراج بسته و روشن‌کردن Apache و MySQL، فقط این نشانی را باز کنید:

```
http://localhost/erooydad/install.php
```

فرم را با پیش‌فرض‌های XAMPP (root بدون رمز) پر کنید و «نصب کامل را اجرا کن» را بزنید. نصب‌کننده به‌تنهایی انجام می‌دهد: ساخت دیتابیس، اجرای `database/schema.sql`، ساخت کاربر محدود دیتابیس، نوشتن `.env` با کلیدهای تصادفی و ساخت حساب مدیر اول با نقش `system_admin`. بعد از پیام موفقیت، `install.php` را حذف کنید و با همان شماره/رمز وارد شوید.

نکتهٔ امنیتی: نصب‌کننده فقط وقتی فایل `.env` معتبر نباشد فرم را نشان می‌دهد؛ پس از نصب قفل می‌شود. آزمون `tests/installer-test.mjs` کل این مسیر را روی ریشهٔ تازه می‌سنجد.

## مراحل نصب (روش دستی)

1. **استخراج** — بستهٔ ZIP را با «Extract All» ویندوز در `C:\xampp\htdocs\` باز کنید؛ پوشهٔ بالایی `erooydad` ساخته می‌شود.
2. **سرویس‌ها** — XAMPP Control Panel: **Apache** و **MySQL** را Start کنید.
3. **دیتابیس** — phpMyAdmin: یک دیتابیس با نام `erooydad` و کاراکتر `utf8mb4` بسازید و فایل `database/schema.sql` را Import کنید (پایهٔ کامل + seedها).
4. **پیکربندی** — فایل `.env` را در ریشهٔ `erooydad` بسازید (الگو: `.env.example`):

   ```env
   APP_NAME=ای‌رویداد
   APP_BASE_URL=http://localhost/erooydad
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_NAME=erooydad
   DB_USER=root
   DB_PASSWORD=
   ```

   رازها را بسازید و اضافه کنید:

   ```
   php deployment/local-xampp/generate-secrets.php
   ```

   خروجی (`APP_KEY`، `EMPLOYEE_HMAC_KEY`، `TICKET_SIGNING_KEY`) را در `.env` بگذارید. بدون سه رازِ ≥۳۲ نویسه‌ای، سامانه پاسخ **503** می‌دهد.

5. **مهاجرت** — فقط همین یک بار و همیشه پس از schema:

   ```
   php deployment/local-xampp/migrate.php
   ```

   روی نصب تازه «۰۰۲» را اعمال می‌کند؛ اجرای دوباره گام‌های تکراری را رد می‌کند (بی‌خطر است).

6. **مدیر اول** — ساخت مدیر با رابط خط فرمان:

   ```
   php deployment/local-xampp/create-admin.php
   ```

   شماره موبایل، نام و رمز (۱۲ تا ۲۰۰ نویسه) را وارد کنید. برای دسترسی مدیریتی نقش `system_admin` بدهید (یا از `setup-local-test.php` برای محیط آزمایشی کمک بگیرید).

7. **باز کردن** — مرورگر: `http://localhost/erooydad/` (مطابق `APP_BASE_URL`).

## راستی‌آزمایی دستی (بند ۸۵ نقشه‌راه)

روی همان ویندوز، این موارد را یک‌به‌یک ببینید و نتیجه را در گزارش انتشار ثبت کنید:

- [ ] صفحهٔ اصلی با فونت فارسی محلی و چیدمان راست‌به‌چپ بالا می‌آید.
- [ ] `/login` و `/register` کار می‌کنند؛ خطای رمز/موبایل پیام فارسی می‌دهد.
- [ ] ساخت حساب + ورود ← پنل فراگیر (`/account`).
- [ ] ساخت یک رویداد در پنل admin، انتشار، و دیدن آن در صفحهٔ عمومی.
- [ ] ثبت‌نام رویداد پولی ← صفحهٔ sandbox ← سناریوی `success` ← بلیت صادر می‌شود.
- [ ] چاپ بلیت (`/tickets/{id}/print`) و دانلود یک خروجی XLSX در مرورگر ویندوز.
- [ ] PWA: `manifest.webmanifest` لود می‌شود؛ نصب/افزودن به صفحهٔ اصلی در مرورگر موجود.
- [ ] خروج و ورود دوباره؛ «خروج از همهٔ دستگاه‌ها» نشست قبلی را باطل می‌کند.

## نکات رایج

| علامت | علت |
|-------|-----|
| 503 با پیام «پیکربندی امن کامل نیست» | `.env` نیست یا رازها کوتاه/`CHANGE_ME`‌اند |
| 404 «نشانی برنامه معتبر نیست» | `APP_BASE_URL` با مسیر واقعی پوشه هم‌خوان نیست |
| صفحهٔ خطا با شناسهٔ پیگیری | خطا را با `request_id` در لاگ Apache/PHP پیدا کنید |
| دیتابیس خالی/جدول نیست | `schema.sql` را Import نکرده‌اید یا نام دیتابیس در `.env` غلط است |

## به‌روزرسانی نصب موجود

php deployment/local-xampp/migrate.php
